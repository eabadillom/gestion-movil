# Gestión Móvil
Aplicación móvil para sistema de inventarios, facturación y cobranza de FERBO

# Pantallas
- Login
- Cambio de contraseña
- Dashboard (Pagina principal)
- SideMenu (Menu lateral)
- Inventarios
  - Entradas
   - Consulta, ver y envio de evidencias
  - Salidas
   - Consulta, ver y envio de evidencias
  - Traspasos
   - Consulta, ver y envio de evidencias
  - Servicios
   - Consulta, ver y envio de evidencias
  - Ordenes de salida
   - Consulta, ver y cancelar orden de retiro
- Reportes
  - Posiciones por planta
   - Reporte posicion por planta
  - Kardex
   - Consulta y reporte de kardex
  - Entradas
   - Consulta de reporte
  - Salidas
   - Consulta de reporte
  - Inventarios
   - Consulta de reporte
- Facturacion
  - Candado Salida
   - Editar y actualizar un candado de salida

## Nota 
Crear el archivo .env basado en el .env.template y colocar la dirección IP a usar
